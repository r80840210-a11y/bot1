# OrdoGram — demo Telegram bot for Render Web Service

- `/start` generates a random Russian-style `+7` number-shaped placeholder for UI testing.
- `/used` confirms the user has finished testing and then issues an internal demo code.
- `/help` shows commands.

Important: generated numbers are not real assigned phone numbers and cannot receive SMS. The code is generated by this bot, not received from an SMS provider or another service. For real SMS verification, use a legitimate SMS provider and numbers assigned to your account.

## Render
1. Push these files to your GitHub repository.
2. Create/update a Render Web Service.
3. Set `BOT_TOKEN` in Environment Variables.
4. Deploy. The app listens on Render's `PORT` for health checks and uses Telegram polling.
