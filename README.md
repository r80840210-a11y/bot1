# OrdoGram — тестовый бот регистрации

Этот вариант создаёт внутренний шестизначный тестовый код и отправляет его пользователю, который запросил код. Он не арендует телефонные номера, не получает SMS и не пересылает коды от сторонних сервисов.

## Запуск на Render

1. Загрузи файлы в GitHub-репозиторий.
2. В Render создай Background Worker из репозитория.
3. В Environment добавь `BOT_TOKEN` — токен бота от BotFather.
4. Нажми Deploy. Зависимость из `requirements.txt` установится автоматически.

## Команды

- `/start` — приветствие
- `/code` — получить тестовый код

## Важно перед реальным запуском

Это демонстрационный вариант: коды хранятся в оперативной памяти и пропадут при перезапуске; сервер OrdoGram пока не может их проверить. Для production храни коды в своей базе данных, привязывай их к конкретной сессии регистрации, ставь срок действия около пяти минут, помечай использованные коды, ограничивай частоту запросов и проверяй код на сервере. Не используй бота для сбора или пересылки SMS-кодов от других сервисов.

Это тестовый поток кодов, а не сервис реальных телефонных номеров/SMS.
