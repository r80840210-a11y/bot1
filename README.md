# OrdoGram — тестовый бот

1. Загрузи файлы в GitHub.
2. В Render создай Background Worker из репозитория.
3. Добавь Environment variable `BOT_TOKEN` с токеном от BotFather.
4. Deploy.

Команды: `/start`, `/code`.

Это демонстрационный бот внутренних тестовых кодов, а не сервис реальных телефонных номеров/SMS. Коды пока хранятся в памяти и исчезают при перезапуске. Для production свяжи генерацию и проверку кодов с backend и базой данных OrdoGram, добавь срок действия, одноразовое использование и ограничения частоты запросов.
